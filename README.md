# 随手

一个反生产力的待办工具。

不做 DDL，不做统计，不催你，不 judge 你。打开就用，关掉就停。

## 为什么做这个

市面上的 Todo 工具都在教你"更自律"——设截止日期、打优先级、看完成率、回顾总结。但大多数人不需要被管理，只需要一个安静的清单。

随手的理念：**做了就行，不做也行。**

## 功能

- **四种频率** — 每日 / 每周 / 每月 / 一次性
  - 每日：每天重新出现
  - 每周：勾选后本周隐藏，下周一重新出现
  - 每月：勾选后本月隐藏，下月 1 号重新出现
  - 一次性：勾选后永久删除
- **三档重要级** — 红色（必做）/ 黄色（做了有好处）/ 绿色（看心情）
- **优先级排序** — 红色自动排最上面
- **拖拽排序** — 长按拖动调整顺序
- **置顶/置底** — 重要任务一键置顶
- **双击编辑** — 直接修改任务文字
- **折叠已完成** — 一键隐藏已完成任务
- **撤销删除** — 3 秒内可恢复误删任务
- **文件存储** — 数据保存在本地 `todo-data.json`，看得见摸得着
- **零依赖** — 单 HTML 文件，不需要任何外部 CDN

## 快速开始

### 方式一 — 桌面快捷方式（推荐）

1. 双击 `create-shortcut.bat`（只需运行一次）
2. 桌面出现 "Suishou" 图标
3. 随时双击图标启动

### 方式二 — 一键启动

双击 `start.bat`，服务器启动并自动打开浏览器。

### 方式三 — 命令行

```bash
node server.js
```

然后在浏览器打开 http://localhost:3000

## 使用方式

- **添加任务**：输入文字，选频率和重要级，点 + 或按 Enter
- **完成任务**：点击勾选框
- **编辑任务**：双击文字
- **删除任务**：点 ✕
- **排序**：拖拽或用箭头按钮
- **停止服务**：关掉终端窗口

## 文件结构

```
├── start.bat            ← 双击启动（Windows）
├── create-shortcut.bat  ← 创建桌面快捷方式（运行一次）
├── server.js            ← Node.js 服务器（零依赖）
├── todo.html            ← 前端（单文件）
├── todo-data.json       ← 数据文件（自动创建）
├── favicon.svg          ← 应用图标
└── README.md
```

## 系统要求

- [Node.js](https://nodejs.org/) v14+ 已安装并在 PATH 中
- Windows（`.bat` 脚本）或任意系统（手动运行 `node server.js`）

## 技术

- 单 HTML 文件，零外部依赖
- 毛玻璃 UI（CSS `backdrop-filter`）
- `server.js` — 仅使用 Node.js 内置模块（`http`、`fs`、`path`）
- `todo-data.json` — 人类可读 JSON，方便编辑或版本控制

## 备份

`todo-data.json` 就是你的全部数据。丢进云盘（坚果云、iCloud、OneDrive）就是备份。
